Aide

Comment faire, sans toucher au code. Touchez une question pour la déplier.

Ajouter un patient et lui donner son accès
  1. Patients → Nouveau patient : nom et téléphone.
  2. Dans sa fiche, Accès patient : envoyez le lien par SMS, WhatsApp ou e-mail, ou faites scanner le QR code au cabinet.
  3. Le texte du message se change dans Réglages du cabinet → « Message d'accès ».

Lien perdu ou partagé : fiche du patient → Plus → Générer un nouveau code d'accès. L'ancien lien cesse de fonctionner.

Faire un bilan (entrée, suivi, fin de traitement)
  1. Fiche du patient → Bilan (ou Nouveau bilan dans la rubrique Bilans).
  2. Touchez les zones douloureuses sur le schéma, puis l'EVA et le type de douleur. Pour le genou, l'épaule, les lombaires, les cervicales et la cheville, les drapeaux rouges et les tests validés (LR+, LR−, sources) s'affichent : touchez le nom d'un test pour sa technique, « + » ou « − » pour le résultat.
  3. Complétez motif, antécédents, examen, mesures (NPRS, PSFS, Oswestry…) et conclusion. Tout s'enregistre automatiquement ; Terminer ramène à la fiche.
  • Un nouveau bilan reprend le motif, les antécédents, la médication et le médecin du précédent, et affiche l'évolution des mesures (repérage des changements ≥ MID).
  • PDF : un document à l'en-tête du cabinet. Envoyer : en pièce jointe sur téléphone et tablette, ou par e-mail avec le résumé (le PDF se télécharge pour être joint). Copier le résumé : à coller dans Maiia.
  • Les bilans sont visibles par vous seul : vos patients n'y ont jamais accès, même avec leur lien.
  • Le contenu clinique (tests, valeurs, sources) se modifie dans bilan-kine/data.js, les fiches de technique dans bilan-kine/guide.js.
Créer une séance ou un programme pour un patient
  1. Créer (ou un modèle → Utiliser).
  2. Ajoutez des exercices depuis la bibliothèque, réglez effort, repos, répétitions et tours. Glissez la poignée pour changer l'ordre.
  3. « Consigne personnelle pour le patient » : une remarque qui s'affiche pendant l'exercice.
  4. Choisissez le patient, Séance unique ou Programme sur plusieurs semaines (jours et durée), puis Envoyer.

Pour modifier une séance déjà envoyée : fiche du patient → crayon à côté de la séance.

Créer un nouvel exercice
  1. Exercices → Créer un exercice (aussi dans la bibliothèque d'une séance).
  2. Titre et au moins une consigne (une par ligne) sont obligatoires. Ajoutez si vous voulez une image, une vidéo (YouTube, Vimeo…), des mots-clés pour la recherche, la zone, le matériel, les conseils et variantes.

Il apparaît avec le badge « Mes exercices ». Filtre « Mes exercices » dans la liste des sources.

Corriger un exercice (titre, consignes, image, vidéo…)

Ouvrez l'exercice, puis le petit crayon en haut à droite. Laissez cochée « Corriger aussi les séances déjà envoyées » pour que vos patients voient la correction dans leurs séances pas encore faites (ce que vous avez personnalisé pour un patient n'est pas touché).

Un exercice corrigé porte le badge « Corrigé » ; « Revenir à la version d'origine » annule vos corrections.

Exercices favoris et exercices masqués
  • Favori : l'étoile en haut de la fiche d'un exercice. Les favoris s'affichent en premier, et le filtre « ★ Mes favoris » ne montre qu'eux.
  • Masquer un exercice que vous n'utilisez pas (doublon, mauvaise traduction) : lien « Masquer cet exercice de la bibliothèque » en bas de sa fiche. Il n'est pas supprimé : filtre « Exercices masqués » pour le retrouver et le réafficher.
Modèles : pathologies, post-op, prévention, avec niveaux
  1. Modèles → Nouveau modèle : composez la séance, puis en bas choisissez catégorie, zone, niveau et image → Enregistrer le modèle.
  2. Pour le niveau suivant : ouvrez le modèle (touchez son image) → Créer : niveau 2. Il suffit d'ajuster les exercices.
  3. Les niveaux d'un même modèle (même nom) sont regroupés sur une seule carte avec des boutons Niveau 1, Niveau 2…

Depuis une séance en préparation, Enregistrer comme modèle fait la même chose.

Modifier, dupliquer ou masquer un modèle fourni avec l'application
  • Modifier : votre version prend sa place (badge « Ma version »). « Revenir à la version d'origine » la supprime et l'original réapparaît.
  • Dupliquer : crée un nouveau modèle à partir de celui-ci, l'original reste.
  • Masquer : il disparaît de la liste ; filtre « Modèles fournis masqués » pour le réafficher.
Changer le nom, le logo, le téléphone, les textes…

Outils → Réglages du cabinet :

  • nom, profession, logo, e-mail, téléphone, adresse (application et fiches PDF) ;
  • message envoyé avec le lien d'accès, messages d'encouragement de fin de séance, bas de page des PDF ;
  • réglage proposé pour un nouvel exercice ;
  • seuils des alertes « À surveiller » ;
  • catégories de modèles, noms des niveaux (par exemple « Phase 1 »), zones du corps.

N'oubliez pas Enregistrer les réglages en bas de la page. Les autres appareils voient les changements dans les minutes qui suivent.

Afficher une annonce à tous les patients

Réglages du cabinet → « Annonce aux patients » : cochez « Afficher l'annonce », écrivez le texte, et si vous voulez une date de début et de fin. Le bandeau apparaît en haut de leur accueil et disparaît tout seul après la date de fin.

Sauvegarder et restaurer toutes les données

Réglages du cabinet → Sauvegarde → Télécharger une sauvegarde : un fichier avec patients, séances, bilans, modèles, exercices et réglages. Faites-le une fois par mois et gardez le fichier en lieu sûr (il contient des données de santé).

Restaurer une sauvegarde… : choisissez le fichier puis ce qu'il faut restaurer. Rien n'est effacé ; les éléments de la sauvegarde remplacent ceux qui ont le même identifiant.

Réglage unique dans Firebase (message « Firebase refuse l'enregistrement »)

Les réglages du cabinet, favoris et éléments masqués, ainsi que les bilans, demandent des règles dans Firebase, à ajouter une seule fois. Le plus simple : remplacez tout le contenu des règles par le fichier firestore.rules du site, puis Publier. Sinon :

  1. Ouvrez la console Firebase → Firestore Database → Règles.
  2. Juste avant le bloc match /programmes/{id} { (vers la fin), collez :
    match /reglages/{id} {
      allow read: if true;
      allow write: if isKine();
    }

    match /bilans/{id} {
      allow read, write: if isKine();
    }
  1. Cliquez sur Publier.

Le fichier firestore.rules du site contient la version complète à jour.

Ce qui demande encore une modification du code

Une fonctionnalité vraiment nouvelle, une nouvelle page, ou un changement de mise en page. Pour tout le reste (contenu, textes, listes, exercices, modèles, réglages), tout se fait depuis le site.
